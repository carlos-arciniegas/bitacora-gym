# Bitácora de Gym

Registro de entrenamientos y peso corporal, para usar desde el celular.

**Cómo instalarla:** abre el enlace en el navegador del teléfono.
- **iPhone:** Safari → botón Compartir → *Agregar a pantalla de inicio*.
- **Android:** Chrome → menú ⋮ → *Agregar a la pantalla principal* (o *Instalar app*).

Tus datos se guardan solo en tu teléfono, en el navegador. Usa *Historial → Respaldo* para guardar una copia.

Imágenes de ejercicios: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (dominio público).
